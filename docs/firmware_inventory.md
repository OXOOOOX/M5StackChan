- 可以确认是 ESP-IDF 主固件/遥控器项目产物，不是 UIFlow2 脚本运行固件。
- 主固件元数据为 1.2.6，但固定官方源码 `51a0617` 的 `firmware/CMakeLists.txt` 为 1.2.4；不能承诺由当前源码复现此 bin。

- 本次元数据检查不等于对二进制中的 NVS、凭据或全部内容作了完整隐私审计。
- 两份 bin 已在历史 Git 中。新增 `*.bin` 忽略规则不会让已跟踪文件消失；本次保留原文件及索引关系，未删除、改写历史或重新发布。

因此，这两份是有元数据可查的**历史归档**，不是新用户默认刷写入口。UIFlow2 首次运行见[搭建说明](setup.md)。

## 后续发布每个 bin 必填

| 项目 | 内容 |
| --- | --- |
| 目标设备 | 精确型号、接线和 flash 容量 |
| 构建来源 | 源码提交、子模块提交、patch hash |
| 构建环境 | ESP-IDF 版本、生效 sdkconfig、分区表 |
| 镜像 | 文件名、大小、SHA256、合并来源与 flash_args |
| 烧录 | 明确地址；不从文件名推断 |
| 验证 | 构建日志、启动日志、屏幕/输入/收包/动作分别结果 |
| 发布内容 | 源码/补丁和 bin 是否同时更新，README 是否引用实际文件 |

优先在确认来源与验证后使用 GitHub Release 附件保存发布镜像；源码与清洗后的文档保留在仓库。未经来源核对的新 bin 默认由 `.gitignore` 排除。
